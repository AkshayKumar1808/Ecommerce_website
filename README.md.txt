# Ecommerce Website

This is a full-stack ecommerce website project that includes product listing, product details, shopping cart, and user authentication.

## Features

- User Registration & Login
- Product Catalog
- Product Details Page
- Add to Cart
- Checkout Flow
- Admin Panel for Product Management

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript, React (optional)
- **Backend:** Java, Spring Boot
- **Database:** MySQL
- **Version Control:** Git & GitHub
